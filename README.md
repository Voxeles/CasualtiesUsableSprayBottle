# Casualties: Unknown usable spray bottle mod

![Banner](assets/banner.png)

A mod for Casualties: Unknown that allows you to use the spray bottle on yourself for dosing medicine.

One use causes you to ingest 10ml of liquid.

Works in singleplayer and with the Casualties: Together multiplayer mod.

# Installation

1. Download CasualtiesUsableSprayBottle.dll from [Releases](https://github.com/Voxeles/CasualtiesUsableSprayBottle/releases)
2. Put it in "Casualties Unknown Demo/BepInEx/plugins"
